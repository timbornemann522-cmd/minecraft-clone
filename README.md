# BLOCKCRAFT

![BLOCKCRAFT banner](assets/textures/banner.png)

A pixel-accurate Minecraft clone that runs in the browser. TypeScript and
Three.js voxel engine, hand-authored 16x16 pixel textures, mob models built
in headless Blender with Minecraft-exact box geometry and skin UVs, and full
NPC AI (zombies hunt and burn in daylight, skeletons kite and snipe, creepers
hiss and detonate, spiders climb walls, herds panic).

No emojis. All pixel.

---

## Run it

```bash
npm install
npm run dev        # -> http://localhost:5173
```

Production build: `npm run build` (output in `dist/`).

## Controls

| Input | Action |
| --- | --- |
| W A S D | Move |
| Mouse | Look |
| Space | Jump / swim up / fly up (creative) |
| Ctrl or double-tap W | Sprint |
| Shift | Sneak / fly down (creative) |
| Left click (hold) | Mine block |
| Left click | Attack mob |
| Right click | Place block / open crafting table / prime TNT |
| Middle click | Pick block |
| 1 - 9, mouse wheel | Select hotbar slot |
| E | Inventory + 2x2 crafting |
| F | Eat held food |
| F3 | Debug overlay |
| Esc | Pause (saves the world) |

Survival starts you with wooden tools and three apples. Mine, craft, eat,
survive the night. Creative mode is available for free building.

## Feature tour

- **World**: infinite chunked voxels (16x16x16), 128 block height, seeded
  terrain with plains, forest, desert, snowy plains and mountains, oak trees,
  cacti, flowers, lakes and oceans at sea level, cheese + spaghetti caves,
  ore veins by depth (coal, iron, gold, diamond), bedrock floor.
- **Rendering**: face-culled chunk meshes with per-vertex ambient occlusion and
  sky light baked to vertex colors (Minecraft-style smooth shading on hard
  pixel textures), cutout leaves/glass/plants, translucent water, day/night
  cycle with pixel sun and moon, blocky scrolling clouds, distance fog.
- **Mobs**: exact Minecraft box models (see `docs/MODEL_SPEC.md`) built in
  Blender and animated procedurally - walk cycles, head tracking, attack
  poses, hurt flash, creeper fuse pulse, spider leg waves, chicken flapping.
- **AI**: finite state machines per species with vision raycasts, memory
  timers, herd alerts, ledge-safe steering, jump-up-1 pathing. Details in
  `docs/ARCHITECTURE.md`.
- **Survival**: 10 hearts, 10 hunger drumsticks, fall damage, drowning,
  sprint drain, regen, starvation, death and respawn.
- **Items**: hotbar, 27-slot inventory, drag-and-drop stacks, 2x2 crafting in
  inventory and 3x3 at a crafting table (planks, sticks, table, four tool
  tiers times pick/axe/shovel/sword, bow, arrows).
- **Audio**: every sound is synthesized live with WebAudio - footsteps per
  material, digging, explosions, bowshots, zombie groans, skeleton rattles,
  the creeper hiss, animal calls.
- **Persistence**: seed, block diffs, player and time autosave to
  localStorage every 30 s and on pause. Title screen offers Continue/New.

## Asset pipeline

Everything visual is generated by code in this repo:

| Step | Tool | Command |
| --- | --- | --- |
| Textures, skins, GUI, banner | Pillow pixel maps | `python3 tools/textures/gen_textures.py` |
| Mob models (GLB) | Headless Blender (`bpy`) | `bash tools/blender/setup_blender.sh` then `npm run assets:models` |

`docs/BLENDER_PIPELINE.md` explains how to connect Blender, including how to
recover on machines without X11 libraries.
