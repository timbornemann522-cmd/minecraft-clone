# BLOCKCRAFT — MASTER BUILD PROMPT

You are a principal game-engine developer, pixel artist, technical animator, and game-AI engineer. Build **BLOCKCRAFT**, a complete, playable, browser-based Minecraft clone that is as close to the real game as web technology allows. Work autonomously to completion. Stop only on unrecoverable failure, and then report the exact blocker and how to connect the missing tool.

---

## 1. GOLDEN RULES (non-negotiable)

1. **NO EMOJIS anywhere.** Not in code, UI, docs, commits, or chat. All interface language is plain text rendered with an embedded pixel bitmap font.
2. **Everything is pixel art.** Every texture is hand-authored pixel data (16x16 blocks, 64x64 entity skins, small GUI icons). Nearest-neighbor filtering only. Zero anti-aliasing, zero smooth-shaded textures, zero vector art. 3D geometry may be lit smoothly (as Minecraft is), but all maps are crisp pixels.
3. **Model fidelity is sacred.** Every mob is built to Minecraft's exact box-model proportions, pivot placement, and skin UV layout (the standard 64x64 entity skin atlas with per-part texture offsets). When the real game has a box of 8x12x4 pixels pivoting at the hip, BLOCKCRAFT has a box of 8x12x4 pixels pivoting at the hip.
4. **Scale system.** 1 block = 1 world unit. 1 model pixel = 1/16 block. Player eye height 1.62, player collision box 0.6 x 1.8. All mob sizes match Minecraft hitbox and model dimensions.
5. **Reference authority.** Geometry and textures follow canonical Minecraft specifications (Java Edition box models and skin layouts). When reference images are supplied, they override color grading and detail choices but never the geometry law above. Pixel assets are regenerated by a deterministic script so they can be retargeted at any time.

## 3. TEXTURE LAW
- Block textures: exactly 16x16 pixels. Hand-authored pixel maps declared in the generator as palette-index strings (this is the source of truth; the generator writes PNGs deterministically).
- Grass top: 4-5 greens in clumped noise. Grass side: dirt with a green 4-5 px irregular lip. Dirt: 4 browns, clustered noise. Stone: 3 grays speckled. Cobblestone: rounded cobble cells with mortar lines. Sand: pale yellow with 2-tone noise. Oak log: bark vertical streaks; top: concentric rings. Leaves: dense green clusters with 1-2 dark holes (alpha). Planks: horizontal boards with seams. Glass: near-clear with white frame and 2 highlight pixels (alpha). Ores: stone base + colored gem clusters (coal black, iron tan, gold yellow, diamond cyan). Water: blue with 2-tone wave pixels (semi-transparent). Bedrock: high-contrast dark blotches. Gravel, snow, crafting-table top/front/side, TNT optional.
- Item icons 16x16 pixel maps: tools (wood/stone/iron/diamond pickaxe, axe, shovel, sword), stick, coal, iron ingot, gold ingot, diamond, apple, bow, arrow, raw beef, raw porkchop, wool block item, eggs.
- Entity skins 64x64 (or 64x32 classic for creeper) authored as pixel maps for every used UV island, matching section 2 palette notes.
- GUI: 9-slice-free simple pixel widgets: hotbar 20x20 slots, selector frame, hearts (full/half/empty), hunger drumsticks, crosshair (inverted color), title logo drawn with the pixel font at 4x scale on a dirt-texture banner.
- Atlas: single 256x256 RGBA atlas (16x16 tiles of 16px) for blocks + items + particles + 10 block-breaking crack stages; premultiplied-safe, tile padding 0 (use inset UVs of 0.5/256 to avoid bleed).

## 4. WORLD AND BLOCKS
- Infinite-feel chunked voxel world: chunks 16x16x16, world height 128, sea level 46. Render distance 6 chunks (configurable 2-10).
- Deterministic seeded terrain: fractal Perlin heightmap (plains/hills/mountains), 3D noise cave carving (cheese + spaghetti-lite), biomes from temperature/humidity noise: plains, forest, desert, snowy plains, mountains. Surface: grass/dirt/sand/snow per biome, stone below, bedrock floor, ore veins by depth (coal 0-64, iron 5-40, gold 5-20, diamond 2-12), water fill to sea level, gravel/dirt patches.
- Vegetation: oak trees (trunk 4-6, leaf blob), cactus in desert, tall grass, flowers (dandelion, poppy) as cross-quads. Decorate per chunk with seeded PRNG.
- Block set (minimum): air, stone, grass, dirt, cobblestone, planks, sand, gravel, oak log, oak leaves (cutout), glass (cutout), water (translucent, no collision, swim physics), bedrock, coal ore, iron ore, gold ore, diamond ore, snow block, sandstone, crafting table, tnt (optional), flowers and tall grass (cross quads, breakable, no drops except flowers).
- Physics: AABB swept collision against voxels, gravity 32 blocks/s^2, jump velocity 8.4 (1.25 block jump), step-up 0.5, swimming (slower, buoyancy, drowning timer 15 s), fall damage (1 heart per block past 3), ladders skip.
- Lighting: per-chunk column sky-light (sunlight falls down from top, propagates 2D flood-fill horizontally with falloff) plus baked smooth ambient occlusion on mesh vertices (the classic 4-vertex AO). Night darkens sky light globally by day-cycle factor. This produces Minecraft's look: smooth shade on cubes, hard pixel textures.

## 5. PLAYER AND INTERACTION
- Pointer-lock first person. WASD, Space jump, Shift sneak (slower, no fall off edges optional), Ctrl or double-W sprint with FOV punch. Mouse look with adjustable sensitivity.
- Survival mode default + Creative toggle (flight: double-space, no damage, infinite blocks).
- Break: hold LMB; per-block hardness with correct relative times (dirt 0.5, stone 1.5 with pickaxe tier gating: wood tools mine stone, iron mines diamond ore...); crack overlay stages 0-9; on break: particle burst, drop item, sound. Wrong tool = slower and no drop for ores.
- Place: RMB with ghost wireframe of target block, places from hotbar if count > 0 in survival; creative = infinite. MMB pick-block.
- Hotbar 9 slots (keys 1-9 and wheel), inventory screen (E) with 27-slot storage grid + 2x2 craft grid optional (defer allowed), drag with mouse. Items stack to 64 (tools to 1).
- Health 20 (10 hearts), hunger 20 (10 drumsticks), sprint drains hunger, starvation at 0 (1 heart per 4 s), natural regen when hunger >= 18. Damage sources: mobs, fall, drowning, explosion, cactus, void.
- Attack: LMB click on mob in reach (4 blocks), cooldown 0.6 s, sweep-free single target, knockback both ways, damage numbers per tool (fist 1, wood sword 4, stone 5, iron 6, diamond 7; cooldown display optional).
- Day/night cycle: 10 real minutes per full cycle. Sun/moon quads arc across sky, sky and fog color lerp (dawn/dusk warm tint), clouds: flat scrolling pixel-white slab layer at y=95. Hostile light rule: burn zombies/skeletons in full sun with smoke particles.
- Save/load: seed + block-diff map + player state + time in localStorage (autosave 30 s, save on pause). "New world" regenerates from fresh seed.

## 6. MOB AI (the point of this game)
Shared architecture: per-mob finite state machine + steering + voxel obstacle handling. Perception: vision cone (70 degrees) with voxel line-of-sight raycast, hearing events (explosions, breaking), memory timers. All mobs avoid walking off >3 block cliffs when passive or wandering, jump 1-block steps, unstick by jitter + jump when collision-blocked.

### 6.1 Zombie (hostile)
- States: IDLE, WANDER, CHASE, ATTACK, BURNING.
- Aggro on player within 40 blocks with LOS. Chase speed 2.3 blocks/s (vanilla-ish), never gives up while target alive and within 60 blocks (memory 5 s after LOS break).
- Melee: reach 2 blocks, 3 damage (1.5 hearts) every 1.0 s, arm-raise attack animation, knockback.
- Burns in daylight (damage 1/s + flame particles + smoke), seeks shade while burning (prefers tree canopy / cave / water).
- Group alert: aggroing one alerts other zombies within 16 blocks.

### 6.2 Skeleton (hostile)
- States: IDLE, WANDER, CHASE_TO_RANGE, STRAFE, SHOOT, FLEE.
- Preferred band 8-12 blocks. If closer than 5, backpedal (FLEE short). If farther than 16, close in.
- Shoot: draw bow 1.2 s (arm pose pulls), release arrow with gravity 20, leading prediction on player velocity, inaccuracy 1.5 degrees + difficulty by distance. Arrow damage 2-4 by draw. Arrow sticks in ground 60 s.
- Burns in daylight like zombie.

### 6.3 Creeper (hostile)
- States: IDLE, WANDER, APPROACH, FUSE, EXPLODE.
- Approaches silently (no step sounds) within 16 blocks with LOS. At 2.5 blocks radius: FUSE 1.5 s, hiss sound (procedural white-noise crescendo), body flashes white (emissive pulse 8 Hz). If player breaks LOS/leaves 4 blocks during fuse: 50 percent chance to abort (vanilla-ish cancel), else complete.
- EXPLODE: crater radius 3 (block strength attenuated: dirt/sand destroyed, stone damaged to cobble at rim, bedrock/ores survive), entity damage 40 * falloff, screen shake. Explosion noise alerts mobs within 24 blocks.
- Movement identical to zombie (2-legged stump walk) with 4-leg gait animation (alternating diagonal legs).

### 6.4 Spider (hostile at night / neutral day)
- States: IDLE, WANDER, PROWL, POUNCE, CHASE, CLIMB.
- Neutral in bright light when unprovoked (wander), aggressive in darkness or when damaged.
- Speed 2.6. Can climb any full block face vertically (switch to CLIMB when blocked and target above; stick to wall, animate legs faster). POUNCE: when 3-5 blocks away and LOS, leap with horizontal velocity toward player (damage 2 on contact).
- Does not burn in daylight. Dark-red eye quads glow at night (emissive map or material).

### 6.5 Passive pack (Pig, Cow, Sheep, Chicken)
- States: IDLE, WANDER, FLEE, PANIC (chicken only adds FLAP).
- Wander: pick random reachable point within 8 blocks every 4-9 s, walk 1.2 blocks/s with head bob and tail/ear wiggle idle animation. Herd cohesion optional light (keep within 6 of nearest same species).
- FLEE on damage for 8 s at 2.0 blocks/s from attacker, jump while fleeing.
- Sheep: random wool thickness look (wool layer on/off per individual), eat grass (head down 2 s, grass block becomes dirt visually for a moment).
- Chicken: random wing-flap jump (no fall damage, slow-fall constant), lays egg item every 5-10 min (optional).
- Spawning: passives spawn on grass in groups 2-4 in daylight near fresh chunks; hostiles spawn on solid blocks in darkness (light 0-7): caves and night surface, groups 1-3; never within 24 blocks of player; despawn beyond 80 blocks (except named/leashed: skip). Entity cap 50.

### 6.6 Animation (all mobs via GLB node transforms)
- Walk cycle: legs and arms sin-phase swing scaled by speed (amplitude 30-45 degrees). Quadrupeds use diagonal pairs. Head yaw/pitch tracks target (player) within limits (60 yaw, 30 pitch) with smoothing. Idle breathing scale pulse 1 percent. Attack pose: arm up 2 seconds. Hurt: red flash on material + tilt. Death: rotate 90 degrees fall + sink (0.5 s) then remove. Creeper fuse: body scale 1.05 pulse + white flash. Spider legs: 8 legs with wave-phase gait. Chicken wings flap 12 Hz during jump.

## 7. TECH STACK AND ARCHITECTURE
- TypeScript + Vite + Three.js (WebGL2). No game framework, no emoji in any file.
- Renderer: one THREE.Scene, chunk meshes as BufferGeometry (positions, normals, u00, uv, ao, light), material: MeshBasicMaterial-style custom ShaderMaterial with atlas texture (NearestFilter), per-vertex sky light x AO shading, day-cycle tint, fog. Second pass material for cutout (leaves/glass/flowers) and third for translucent water (front-face, subtle scroll).
- Mesher: per-chunk rebuild on edit; face culling against neighbors; per-vertex AO (side1+side2+corner -> 0..3); plants as X-quads. Dirty-chunk queue, max 4 rebuilds/frame, frustum culled via chunk bounds.
- Entity system: fixed-step simulation 60 Hz decoupled from render. Each entity: FSM, steering controller, AABB physics vs voxels (same solver as player), animation mixer hand-rolled on GLB node map (no AnimationClips required; procedural).
- Asset pipeline (Blender): headless Blender Python (bpy) builds every mob from box primitives with Minecraft box-UV unwrapping, applies generated skin textures, parents parts with named nodes (head, body, arm_left, arm_right, leg_left, leg_right, leg_fl_..., wing_*, leg_0..7), exports GLB per mob to assets/models/. Game loads GLBs and animates nodes procedurally. The pipeline is deterministic and re-runnable: tools/blender/build_models.py.
- Audio: WebAudio only, all sounds synthesized (noise bursts + filters + envelopes): step per material, break, place, hurt, explosion, bow, arrow hit, zombie groan, skeleton rattle, creeper hiss, spider hiss, cow moo, pig oink, chicken cluck (all as shaped noise/oscillator envelopes - no emoji, no files).
- UI: HTML overlay + canvas pixel-font renderer (5x7 glyphs for A-Z, a-z, 0-9, punctuation). Screens: title (logo + Singleplayer / Options / Controls), pause (Resume / Options / Save and Quit), death (You died! + Respawn), options (render distance, sensitivity, volume, invert-Y). Hotbar + hearts + hunger + crosshair + F3 debug + inventory grid.
- Persistence: localStorage JSON per world: seed, diffs (x,y,z -> block id), player, time, entities optional.
